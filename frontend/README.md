# Web — Empório Henz

Frontend moderno construído com **Vue 3**, **Vite**, **Tailwind CSS v4**, **Vue Router** e **Pinia**.

## 🚀 Como Executar

### Desenvolvimento

```bash
# Na raiz do monorepo
bun --filter web dev

# Ou direto na pasta apps/web
bun dev
```

Inicia em `http://localhost:3000`.

### Build

```bash
bun --filter web build
```

### Checagem de Tipos e Lint

```bash
bun --filter web check-types
bun --filter web lint
```
